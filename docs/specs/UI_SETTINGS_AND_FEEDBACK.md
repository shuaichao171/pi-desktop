# 设置、反馈与控件规则

对应 UI-001、002、012、014、027。UI-011 设置搜索、项目默认值设置页及关于页已按用户要求移除；设置通过分类导航访问。

- 操作提示独立于菜单、侧栏和当前会话渲染。以操作和目标去重，防止重复请求；成功短暂显示，失败保留到关闭，可查看详情和重试。文件夹和编辑器重试捕获原路径；导出重试校验原会话，切走后提示返回原会话，避免导出错误对象。
- 设置草稿只在内存中。供应商连接、模型编辑和凭据通过统一的 dirty/saving/save 协议报告。切换供应商、分类、Esc 或关闭设置均遵守离开保护。保存并继续串行保存草稿，失败留在当前页；保存过程中不能放弃、继续离开或重复提交。
- 界面文字复用语义字号；代码/文件/Diff 与命令输出分别使用 `--pd-code-font-size` 和 `--pd-command-font-size`，12–24px 独立保存与重置，不改变控件或图标尺寸。被阻止的存储仍允许当前窗口调节。
- 模型能力来自目录中的 input/reasoning，元数据缺失表示未知。选择器呈现能力标记，并允许仅看支持图片的模型；有图片草稿时提示兼容性，由用户主动选择，绝不自动换模型。
- 控件沿用现有组件：菜单行的最小高度、图文间距、焦点边框和圆角使用共享规范；放大字号时允许控件增长。交互菜单/搜索结果显示时抑制被动 Tooltip，保留原有关闭、避让与焦点恢复。

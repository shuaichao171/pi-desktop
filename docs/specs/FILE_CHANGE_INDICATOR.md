# 修改文件数感知与显示（轮次徽标・会话汇总・转录回退）

借鉴 Claude Desktop 对每轮文件修改的感知呈现：产生文件修改的轮次可见「N 文件」入口、悬停／列表可查看路径清单与增删行数、点击进入差异审查，并在会话层给出「本次对话共修改 N 个文件」的汇总。轮次卡片、运行摘要与审查窗口的既有设计见 `docs/specs/CONVERSATION_FILE_CHANGES.md`；本规格补充其上新增的感知层。

## 数据源优先级

| 优先级 | 来源 | 粒度与内容 |
| --- | --- | --- |
| 1（恒可用） | `fileChangeTurns`（`packages/agent/src/fileChanges.ts` 的 `SessionFileChanges` 跟踪器，经 `ready` / `file-changes` 事件发布） | 每轮（run）每文件：相对工作区路径、`added/modified/deleted`、精确增删行数（快照行级 LCS）、二进制／超大标记；差异经 `getFileChangeDiffs` 按需现算 |
| 2（回退） | 转录工具调用聚合（`packages/ui/src/fileChangeSummary.ts`） | 跟踪器出现之前录制的旧会话：`edit`/`write` 已完成调用的 `files` 参数按 run 去重并集；`edit` 结果差异行可解析时给出增删计数 |

说明：Pi SDK 事件本身不提供文件修改数据；优先级 1 是 pi-desktop 自有的内联扩展在 `tool_call`／`tool_execution_end` 钩子处对文件做前后快照得到的，随会话分支持久化（`pi-desktop:file-changes-v1` custom entry）并在恢复时重放。因此只要会话由带跟踪器的版本录制，优先级 1 恒有明细，回退仅在旧会话上生效。

合并规则（`mergeTurnFileChanges`）：跟踪器按路径权威——同轮同路径保留记录项；回退只补充该轮记录中没有的路径；完全没有记录桶的 run 作为新轮追加。会话汇总（`unionFileChanges`）为全部轮次的路径并集，同路径首见（即记录项）优先，按路径排序。

## 展示与交互

- 轮次徽标：产生文件修改的轮在其回答下方渲染本轮变更卡（标题即「已修改 N 个文件」，单文件为文件名），运行中在输入框 dock 显示当前轮紧凑胶囊。此为既有行为，回退数据同样汇入。
- 悬停／清单：变更卡默认列出前三个文件（完整相对路径 + 类型图标 + 变更状态 + 增删统计），「显示其余 N 个文件」展开。审查窗口列出全部文件（可滚动）。>50 的大清单自然由「前 3 + 展开」与滚动列表承载。
- 点击文件：打开统一审查窗口（`ChangesDialog`）。差异为会话记录快照，非 Git 实时读取；无记录差异的回退路径显示「已记录文件更改，暂时无法预览文本差异」。
- 会话汇总：空闲（非 busy）且存在按轮归属的改动时，输入框 dock 显示「本次对话 · 已修改 N 个文件 · +a −d」胶囊，点击打开会话范围审查窗口。仅旧数据（`runId: null` 桶）的会话沿用对话末尾的「本次对话」卡片，不重复显示胶囊。

## Git 与非 Git 行为

- 跟踪器不依赖 Git：行数统计来自文件前后快照的行级差异，非 Git 仓库同样有完整路径、状态与增删计数。Git 仅用于跟踪器 shell 类工具的改动范围扫描（`git ls-files`，失败时退化为目录遍历）。
- 工作台文件树的 Git 状态、`git diff` 查看等属于版本控制面板，与本感知层相互独立。
- 回退层与 Git 无关；`write` 重写整文件、`edit` 结果被截断或混入无法解析的调用时，计数不可知即省略（纯清单降级，统计组件自动隐藏）。

## 性能策略

- 聚合全部为纯函数并 `useMemo` 缓存（依赖 `cwd` 与 `activities`），路径规范化为词法操作，不做文件系统访问。
- 差异仍按需现算（打开审查窗口时按 scope 拉取），变更事件不携带差异文本；回退路径在差异加载完成后补「不可用」占位，不额外请求。
- 会话汇总仅是并集计数与既有统计组件，无新增 IO。

## 限制

- 回退层无法区分新增／删除（无前后快照），统一标为「修改」；多次编辑同一文件的行数为各次调用计数之和，可能高于首末快照差。
- shell（bash／PowerShell）写出的文件不在回退聚合内（无法从命令行静态归因）；跟踪器会话不受此限制。
- 回退路径须与工作区路径大小写一致（词法匹配，仅盘符大小写无关）。
- 审查窗口中的回退文件没有差异正文，仅清单与（可用时的）计数。

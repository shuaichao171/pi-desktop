# 对话文件变更

显示本次对话中工具执行所记录的累计文件差异。运行时使用输入框上方的紧凑摘要，结束后在对话末尾显示文件卡片；通过同一个审查窗口查看文件和原始差异。

## 范围与参考

参考本地 `D:\codex-re` 的 v26.917.51856 样本：`local-conversation-turn-8079af1a75b3.js` 的运行中输入框摘要及结束后的变更入口、`conversation-blocks-ca975d4c03b3.js` 的 `GS/KS/JS` 组件及前三个文件披露方式。项目沿用自己的文件类型图标和审查对话框。

`SessionFileChanges` 按 Pi 会话的当前分支恢复并累计工具快照，`UiFileChange` 没有运行 ID。界面因此只保留一份明确标注“本次对话”的汇总，放在当前时间线末尾；不会把同一份累计数据复制到历史回答中。下一次运行开始时，该汇总重新呈现为输入框上方的摘要，已有记录继续保留。

| 入口 | 数据范围 | 用途 |
| --- | --- | --- |
| 过程中的工具详情 | 单次工具调用及其返回内容 | 阅读具体命令、输出和工具差异 |
| 本次对话文件变更 | 当前会话所选分支累计记录的执行前后文件快照 | 查看本次对话记录到的改动 |
| 工作台 Git | 当前工作区的 Git 状态及暂存／未暂存差异 | 审查工作区当前版本控制状态 |

## 展示与操作

- 没有记录时，摘要、卡片和文件审查入口均隐藏。
- 运行时，输入框上方的紧凑胶囊显示文件数和可用的增删行数。点击主要区域打开审查；点击列表开关显示可滚动的文件列表，点击文件直接选中该文件。点击外部或按 Esc 收起列表，Esc 不停止正在运行的任务。
- 运行结束后，对话末尾显示卡片。单文件标题包含文件名，不再重复一行文件列表；多文件显示数量，默认列出前三个文件，并提供“显示其余 N 个文件”和“收起文件列表”。
- 卡片主标题、“查看更改”和文件行都能打开同一审查窗口。主标题和“查看更改”默认选中首个文件，文件行直接选择对应路径。
- 文件行使用类型图标、较弱的目录文字、文件名、变更状态和增删统计。路径以完整路径区分同名文件，较长路径截断显示并可通过标题查看；窄窗口精简次要状态文字。
- 运行和结束之间切换时，已打开的审查窗口保持挂载和文件选择。快照更新后继续显示同一路径；选中文件从记录中移除时改选首个文件，不因原路径之后重新出现而跳回。
- 入口切换或文件移除导致当前聚焦的按钮消失时，焦点回到新的变更入口；全部记录移除后回到输入框。仍在编辑器或审查窗口内的焦点不受影响。
- 切换工作区或会话时，以工作区、会话路径和会话 ID 重置组件。文件列表展开状态与打开的审查窗口不带入其他会话；会话加载期间隐藏旧入口。

## 审查窗口与键盘

审查窗口使用原生模态 `dialog`，宽窗口左侧列文件、右侧显示差异；窄窗口改为上方文件列表和下方差异。窗口标题显示文件数和累计统计，正文明确说明其来源是本次对话工具执行记录。

- 打开时焦点位于关闭按钮；Tab 在窗口内导航。文件列表只有当前选中项进入 Tab 顺序，方向键上下选择，Home／End 跳到首项／末项，并将选择滚入可见区域。
- Esc 或关闭按钮关闭窗口。关闭后返回仍可用的原始触发按钮；如果运行状态变化或文件移除导致触发按钮消失，则回到当前变更入口或输入框。
- 差异区域可以获得键盘焦点并独立滚动，显示旧／新行号、增删高亮和 hunk 边界。行号不进入复制文本。
- “复制路径”复制记录中的完整显示路径；“复制差异”复制原始统一差异字符串，没有差异文本时禁用。复制成功或失败均显示反馈，切换文件时清除旧反馈，迟到的复制结果不会覆盖其他文件的提示。
- “自动换行”切换长行折行；默认保留原行并允许水平滚动。换行选择仅影响本次打开的审查窗口，不修改文件或差异内容。

## 快照与统计语义

审查读取 store 收到的 `UiFileChange` 快照，不在点击时查询当前磁盘或 Git。审查期间收到新的累计快照会更新内容，窗口中的差异并非打开时冻结的一份副本。

记录来源为 `edit`、`write`、`bash` 和 `powershell` 执行前后的实际文件内容。连续工具操作累计变化；检测到两次工具之间的外部编辑时，该文件从新的基准记录。记录通过 Pi 会话 custom entry 保存，并随当前分支恢复。旧会话缺少执行前记录时无法补回。

仅跟踪工作区内普通文件。命令扫描、读取、持久文本及差异预览均有数量或大小上限；命令扫描遵循项目忽略规则并跳过常见依赖和构建目录，超大项目可能仅记录部分改动。

二进制、过大或不可读取文本的记录显示对应说明。`null` 表示未知行数，不转换为零；全部未知时不显示总行数，部分未知时汇总已知项并显示星号和辅助说明。某侧统计未知但另一侧可用时，未知侧使用破折号。已知行数为零则正常显示零。

# 对话中的排队指令

参考本地 `D:\codex-re` v26.917.51856 的 `queued-message-list-c7ef5642867a.js`（`De/J` 列表、单行摘要、操作菜单与排序）和 `app-primary-923a2b3e8cd1.js`（`$dt/eft` 主输入框编辑、原队列位置恢复）。

## 展示与操作

- 队列紧贴输入框上沿，使用紧凑的单行摘要，不再给每条消息叠加展开箭头、排序箭头和编辑按钮。所有项目位于最高 30dvh 的滚动列表中；附件显示类型图标与数量，点击摘要可查看完整文字及附件名称。
- 行末保留“引导”、删除和更多操作。更多菜单提供编辑、完整内容、上下移动、暂停／继续，以及默认排队设置；菜单支持方向键、Home／End、Esc 和 Tab。
- 多条已接收的同类型输入可以通过拖动柄排序，也可聚焦拖动柄后按上下方向键。待确认与编辑中的项目不参与排序；引导和后续输入保持各自的执行队列。
- “引导”把同一条后续输入转入引导队列，在 SDK 下一次输入接收点处理，不调用停止任务，不复制成另一条消息。
- 暂停只暂停后续输入，当前任务与引导继续。暂停后显示继续入口，即使队列为空也能恢复。重启后的未确认项仍须明确确认，暂停／继续不自动确认它们。
- 运行中的 bash／PowerShell 命令可单独打断而不停止任务：命令卡头部提供「打断」按钮，队列「更多」菜单顶部提供「打断并引导」（后续输入先转引导再打断）与「打断当前命令」（已引导项直接打断），仅在存在运行中的 shell 命令时可用。被杀的命令以退出码 130 失败并在输出尾部标注「[interrupted by user]」，模型据此继续；随后引导在 SDK 下一个输入接收点自然送达，无需整轮停止。
- 输入框右下共用一个主按钮：空闲时显示发送箭头，任务进行时显示停止方块，即使有未发送内容也仍可停止；点击停止保留普通草稿、附件和队列。工具栏不再提供单独的停止或引导按钮，停止请求处理期间禁用重复点击。
- 默认为忙时 Enter 排队、Ctrl／Cmd+Enter 引导。“设置 → 常规 → 任务进行时按 Enter”可将默认动作切换为引导，Ctrl／Cmd+Enter 则反向改为排队；Shift+Enter 始终换行。偏好在本机保存，并立即同步至输入框提示、快捷键设置页和队列更多菜单；菜单中的默认排队开关操作同一偏好。空闲时 Enter 和发送按钮仍直接开始任务。

## 在主输入框编辑

“编辑”先以 `beginEdit` 暂存该条输入，再在主输入框区域显示编辑表面，原行标记“编辑中”。该条输入在保存或取消前不会被 SDK 消费，其他消息可以继续执行。每个会话最多暂存一条编辑。

普通草稿的正文和附件保留在独立状态中。保存和取消后回到原草稿，不把普通草稿误发成队列修改。编辑原消息的附件以只读名称显示，原始图片及文字内容始终留在后端，保存仅替换正文。

Enter 保存，Shift+Enter 换行，Esc 取消。Esc 在整个编辑区域中生效，包括按钮聚焦时，不向对话的停止快捷键冒泡。保存使用原输入 ID，并恢复到同类型队列原有位置；取消恢复原正文与附件。有附件的输入可以保存为空正文，无附件时禁止空白。

切换会话后，该输入保持暂存状态，返回后可从菜单继续或取消编辑。未保存文字在本次应用运行期间按工作区、会话路径、会话 ID、输入 ID 和编辑版本缓存（最近 50 项）；新一轮编辑不会恢复已取消的旧文字。应用重启后暂存项转为待确认，保留原消息，避免自动执行不确定输入。

保存失败时保留编辑正文。若后端回执丢失或重启导致输入已离开编辑状态，界面依据最新快照禁用重复保存，允许复制编辑文字后本地取消。已消费的输入不能重新被修改。项目删除、弹窗关闭、排序与失败恢复均处理键盘焦点。

## 协议与一致性

队列读写携带 `{cwd, sessionPath, sessionId}`。renderer IPC 要求完整作用域，Agent 再与当前会话比对；切换会话后到达的旧请求不能操作新会话。组件身份包含会话路径，同一 ID 的不同会话文件不共享编辑状态。

快照含队列版本、暂停状态和条目状态。界面使用请求代次及单调版本过滤旧响应，现代接口未就绪时禁止修改，不绕过版本检查降级调用旧接口。后端在持久化成功后才改动 SDK 队列，以请求 ID 保证重复请求幂等。

`beginEdit` 从 SDK 队列暂时摘下原消息并保留账本位置；`edit/cancelEdit` 根据当前账本顺序恢复。恢复确认也使用同一顺序，避免逆序点击确认导致显示顺序与实际执行顺序不同。附件原始数据、稳定输入 ID 和队列类型均保留。

打断命令通过 `agentInterruptShellTools` 通道（`agent:interrupt-shell-tools`）下发，同样携带 `{cwd, sessionPath, sessionId}` 作用域，可选 `toolCallId` 精确到单条命令；Agent 侧用自有的 shell 运行注册表（按会话 ID 隔离）定位子进程并杀整棵进程树，返回本次打断的命令数。旧版自定义 Pi 引擎缺少所需 SDK 导出时自动退回内置 shell 工具（不支持打断，不影响启动）。

# 设置中的更新操作

- 始终显示“检查更新”和“安装更新”两个独立按钮；已有下载包时安装按钮显示“安装并重启”。
- 检查按钮显式调用 `checkForUpdates(false)`，只查询可用版本，不发起下载或安装。发现新版本后可以再次检查。
- 安装按钮只在发现版本、下载就绪或可重试的更新失败状态下可用，调用 `installUpdate()`；未下载的版本会先下载，随后安装并重启。
- 没有新版本、检查中、下载中、安装中或当前环境不支持更新时，禁用对应操作，避免重复请求。
- 自动检查仍只检查；中英文说明必须准确说明下载和安装由独立按钮触发。

验证：更新服务现有测试；真实构建的模拟 bridge 检查两个按钮状态及调用边界，确认检查不触发安装，截图检查待检查和发现版本状态；类型检查及构建。

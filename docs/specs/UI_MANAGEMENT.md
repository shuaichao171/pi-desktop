# 会话、自动化与插件管理 UI

本规范对应 UI-008、UI-018、UI-019、UI-024、UI-025、UI-026。实现保留已有侧栏分组、排序、未读与项目元数据，不启动额外服务或真实自动化任务。

## UI-008：独立会话运行状态

- `UiSessionSummary.runtime` 与 `session-runtime` 事件使用工作区和会话路径定位，状态为 `idle`、`running`、`waiting-input`、`waiting-approval`、`failed`。
- 每个真实 runtime 提供状态。输入/选择/编辑扩展对话框为等待输入，确认及项目信任为等待授权；通知不产生等待状态。并发等待采用独立 token，最后一个请求结束后才退出等待。
- 主快照包含所有已加载 runtime 的轻量摘要，更新不复制聊天正文或附件。后台状态事件不修改当前会话的正文、状态或焦点。
- 尚未写出第一条消息但正在运行/等待/失败的 runtime 也可出现在列表中，避免后台扩展指令失去入口。
- 行显示当前运行/等待/失败状态；项目及自定义组标题分别聚合运行、待处理、失败、未读数量，折叠后保留。聚合不依赖筛选后的可见行，包含项目内置顶会话，排除归档会话。
- 成功完成变为 idle；失败维持到下一次运行开始；未读仍按原有已读机制处理，不由运行状态推断。
- 验证：`multi-runtime.test.mjs` 使用真实离线 Pi runtime 验证 A 运行时切至 B、后台等待授权、未持久化等待会话可达、解除等待、失败及后续成功清除。`management-state.test.mjs` 验证事件与工作区身份、列表迟到响应及聚合。

## UI-018：移入回收站确认

- 原生 modal dialog 展示会话标题、工作区和“移入应用回收站”语义，明确不删除项目文件。
- 取消和 Esc 不提交；提交以同步 ref 防重，处理中禁止关闭与再次提交。失败留在同一个确认窗，保留完整目标和错误，允许原位重试。
- 成功发布共用操作反馈，焦点优先回到相邻会话；没有相邻行则回到列表。取消回到原菜单触发器。
- 回收站后端与组成员清理由原有 `deleteSession` 协议负责。
- 验证：原有 `session-delete.test.mjs` 验证回收站移动、组清理及复制失败不丢原文件。renderer 场景涵盖 Esc、重复激活、失败重试和焦点返回。

## UI-019：按工作区请求状态

- store 提供 `workspaceSessionRequests[cwd]`，显式保存 `idle/loading/refreshing/error`、请求 ID 和错误，不用“列表是否为空”推断状态。
- 首次读取为 loading；保留缓存刷新为 refreshing；失败保留已有列表并提供该项目的局部重试。失败状态不会自动无限重试。
- 每个工作区独立递增请求 ID；新请求、bridge 替换后，过期成功及过期失败均不覆盖新状态。新 runtime 事件优先于在途列表旧摘要。
- 验证：`management-state.test.mjs` 覆盖一个项目失败不影响其他项目、缓存保留、重试为空列表成功、过期失败与后台事件竞态。

## UI-024：自动化最近结果

- 计划启用/暂停与运行结果分开呈现；启用的失败计划同时显示“已启用”和最近失败时间，运行中另有状态与停止操作。
- 最近已结束运行按 `startedAt` 排序选取，不假设 snapshot 数组顺序；无运行显示明确空状态。
- 最近结果按钮直接打开对应历史记录，并滚动/聚焦该记录。历史支持全部、运行中、成功、失败、取消、中断筛选，保留现有打开会话与停止入口。
- 验证：`management-state.test.mjs` 覆盖乱序输入、不同计划和状态过滤。renderer 验证启用与失败并存、具体记录定位及成功筛选。

## UI-025：分层自动化编辑

- 编辑分为“做什么、在哪做、何时做”。模型与思考选项默认折叠；已有非默认配置展开，摘要持续显示当前选择。
- 时间部分持续显示人类可读计划和明确时区。一次性时间保留原有本地日期/时区语义；不新增独立未来触发时间算法。
- 表单主体可滚动、底部保存按钮保留；窄窗字段单列。输入、错误及说明使用语义字号。
- 验证：renderer 场景包含不打开模型选项创建默认任务、编辑非默认配置、680px/20px 字号下短窗保存区域截图。

## UI-026：插件能力分组

- 按 extensions、skills、prompts、themes 固定顺序分组并显示数量，正常组可折叠。包含错误的组持续展开，活动筛选命中组自动展开。
- 资源名称、描述、启用状态及错误优先展示；错误使用正常可读字号。路径按需展开，可精确复制并显示复制失败反馈。
- 列表/详情保留原有开关与预览操作，所有动作使用完整 scope/kind/path 身份。
- 插件与自动化私有 CSS 不再使用 9px/10px 关键状态字号；单行搜索框改用 min-height 与对称 padding，多行说明保持自然排版。
- 验证：`management-state.test.mjs` 覆盖30个混合资源的分组、唯一归属和错误组标记；renderer 场景验证折叠、筛选展开、错误可见、路径复制及开关目标一致。

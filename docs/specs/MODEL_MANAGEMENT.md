# 模型管理

2026-09-26：参考 ZCode 的 `ModelProviderSection`、`SectionLayout`、`InlineEditableProviderCard`、`ProviderFormControls` 与模型元数据对话框，调整 Pi 模型管理。

- 页面保持供应商导航和详情两栏。刷新、添加供应商位于页头，当前会话模型和思考级别为次要信息。
- 2026-09-27：详情紧凑化。供应商详情仅显示地址（及协议徽标）与模型列表；名称、地址、协议、请求头、系统代理与凭据收进“编辑设置”模态对话框，点击详情头部按钮打开。未保存关闭对话框同样触发丢弃保护；连接保存后对话框保留以便继续配置凭据。
- 自定义可编辑供应商在编辑对话框内修改名称、地址、协议；请求头与系统代理收在高级配置。Pi 写入完整供应商配置，使用明确保存/取消事务，不直接照搬 ZCode 的逐字段自动保存。
- 内置及不兼容的自定义配置在编辑对话框中只读显示连接字段；凭据使用已有独立接口。API Key 留空保持原值，失败保留输入；请求头密文保留与代理继承语义不变。
- 模型列表持续显示，添加/编辑在独立模态对话框中完成；成功才关闭，失败保留草稿，保存中禁止关闭与重复提交。重复模型 ID、容量、Google 独立输出上限及思考映射继续校验。
- 获取模型为独立导入事务：使用已保存连接读取目录，搜索/勾选新增模型，保留原有模型；确认才写入。关闭或过期响应不得修改目录。它不是推理连通性测试。
- 2026-09-27：独立“测试实际推理”面板移除，能力整合进模型行：每个模型提供“测试推理”按钮，用已保存凭据发送最小请求（20 秒超时、最多并发 3 个），就地显示延迟或分类错误；运行中可再点取消，设置页卸载时自动取消。测试不写入会话、不修改配置，也不纳入未保存保护。
- 新供应商先选模板，再编辑连接和选择/添加至少一个模型，一次创建；取消不落盘。模板不会覆盖已有供应商。
- 2026-10-10：可编辑性拆分。`editable` 仅表示连接（名称/地址/协议/请求头）可编辑并可删除供应商；`modelsEditable` 表示 models.json 的 `models` 条目可增删改与导入，经独立的 `saveProviderModels` 事务只改写 `models` 数组，连接、`modelOverrides` 及模型上未托管的字段（cost、compat、单模型 api/baseUrl）原样保留。手写的非标准协议、带查询参数的地址、`modelOverrides`、单模型端点、OAuth 凭据等只锁连接，并通过 `readOnlyReason` 显示具体原因；只有 `configModelIds` 中的模型提供编辑/删除。内置供应商（含 models.json 覆盖）的导入只写入新增模型，且在供应商未声明 `api` 时为新模型固定发现所用协议；清空覆盖即恢复内置，删除内置覆盖时保留其凭据。连接保存只回写配置文件中的模型，不再把内置目录写入 models.json。单个格式无效的条目不再导致整页无法加载：它显示为只读，同时阻止所有写入（Pi 会因此忽略整个文件）。
- 连接、凭据、模型、导入及新建草稿统一上报 dirty/saving。切供应商、切设置分类、刷新与关闭有未保存保护；继续编辑返回原焦点，放弃才执行目标动作。所有写入串行，回包绑定当前工作区和操作身份。
- 深浅主题、中文/英文及大字号使用 Pi 语义变量；窄窗口导航保持可用；对话框使用模态焦点、Esc 和焦点返回。

# pai 独立聊天窗口

Windows 的 `pai` 命令会在当前文件夹打开一个只保留聊天区域的 Pi Desktop 窗口。每次调用都可打开新的窗口，完整桌面窗口可以继续使用。

精简窗口保留新建对话和设置入口；新建的对话、@ 上下文引用和消息里的结果文件预览都限定在该窗口打开的文件夹内。项目切换、会话管理和工作台仍只在完整桌面窗口可用，在精简窗口里会被拒绝。每个窗口使用自己的活动会话与浏览器数据，不会抢占已打开窗口；关闭时退出该窗口对应的进程。空闲的数据配置会在下次启动时复用，保留外观和统计开关。模型凭据与会话记录继续存放在原有的 Pi 用户目录中。自动化调度和软件更新由完整桌面窗口负责。

“设置 → 常规 → 对话统计”提供四个独立开关。Token 数量来自 Pi 的实际用量；速度是最近任务的输出 Token 除以该任务运行时间，包含工具等待。会话时间累计各次任务的运行时间，不累计用户闲置时间。旧记录缺少计时信息时显示 `—`。

## 在资源管理器中使用

安装或更新 Windows 安装版后，在资源管理器打开本地文件夹，在地址栏输入 `pai` 后按 Enter，即可打开该文件夹的独立聊天窗口。重复输入可以打开多个窗口。

安装器把原生启动器放在应用目录的 `bin\pai.exe`，并注册 Windows Shell 的 `App Paths\pai.exe`。启动器读取当前文件夹，通过 `--pai --cwd <绝对路径>` 传给桌面应用。它不需要 Node 或 PowerShell，也不会弹出命令窗口。

注册跟随安装范围：当前用户安装只注册当前用户，所有用户安装注册到系统。安装和卸载都不会修改 PATH；资源管理器无需重启就可识别命令。已有其他软件的同名 App Paths 注册会保留；卸载仅删除仍指向本次安装的 Pi Desktop 注册。便携版和调试版不自动注册地址栏命令。

## 在终端中使用

终端通过 PATH 查找命令。如需同时在终端输入 `pai`，可以安装配套命令，并指定实际应用 EXE（不是安装包或卸载程序）：

```powershell
pnpm install:pai --exe "C:\Users\你的用户名\AppData\Local\Programs\Pi Desktop\Pi Desktop.exe"
```

脚本默认写入 `%APPDATA%\npm`，与 npm 的 Windows 命令一样生成 `pai.cmd` 和 `pai.ps1`。启动命令本身使用 Windows 自带 PowerShell，不依赖 Node。安装脚本需要 Node。可以通过 `--command-dir "D:\tools\bin"` 选择其他已经加入 PATH 的目录。脚本只会更新自己生成的文件，发现同名的其他命令时会停止。

`--exe` 绑定安装位置；正常原地软件更新不需要重装命令。升级到包含此功能的版本后才支持独立聊天模式。安装后可在终端使用：

```powershell
pai
pai "D:\项目\带 空格的目录"
pai -Cwd "D:\项目\带 空格的目录"
```

项目路径包含中文、空格、`&`、`%` 或 `!` 时会完整保留。`pai` 只传递目录，不会把目录名称当作命令执行。

终端命令目录必须已经在 PATH 中；新加入 PATH 的目录需要新终端才能识别。如果 PowerShell 的本机执行策略禁止 `.ps1`，可使用 `pai.cmd`。命令处理器不能把 UNC 网络共享作为当前目录；网络共享请先映射盘符，或者从终端显式执行 `pai.cmd "\\server\share\folder"`。

## 开发模式

开发时先构建项目，再把终端命令绑定到本仓库的构建结果：

```powershell
pnpm build
pnpm install:pai --dev
pai "D:\项目\带 空格的目录"
```

`--dev` 绑定仓库和开发用 Electron 的绝对路径；移动仓库后需要重新安装命令。它只更新终端命令，不替换已安装软件的资源管理器地址栏注册。

Windows 打包入口会先编译原生启动器，再将其放入应用目录；`pack:dir` 也包含该文件。调试打包的启动器指向独立的 `Pi Desktop Debug.exe`。macOS 和 Linux 不包含 Windows 启动器。

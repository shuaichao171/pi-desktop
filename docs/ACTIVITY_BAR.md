# 活动栏（Activity Bar）

最左侧的 VS Code 风格图标栏，与侧栏分离，为项目／会话列表让出全部纵向空间。

## 布局

```
┌────┬────────────────────────┐
│ ＋ │ π ←→        🔍  ⇔     │   ＋ 新会话（动作，不切视图）
│ ⚡ │                        │   ⚡ 自动化（切视图）
│ 🔌 │  会话／项目列表         │   🔌 插件（切视图）
│    │  （完整高度）           │   … 扩展贡献位（预留）
│ ⚙ │                        │   ⚙ 设置（钉在底部；红点=有可用更新）
└────┴────────────────────────┘
```

## 交互

- 点击视图图标：切换到该视图；**再次点击同一图标回到会话列表**；侧栏处于收起状态时点击任意图标会先展开侧栏。
- `Ctrl／Cmd + B`：只收起／展开左侧栏（宽度归零），活动栏常驻可见。
- 更新入口归设置页；发现新版本时设置图标显示红点，全局更新提示照常出现。
- 窄窗口（≤ 880px）下侧栏为抽屉式覆盖，活动栏保持可见。

## 扩展贡献接口（预留）

`packages/shared/src/activity.ts` 定义 `UiActivityViewContribution`（id、标题、图标、面板类型、排序），配套 `requireActivityViewContribution` 负载校验。插件系统开放后，扩展可注册自定义活动视图：图标出现在插件图标下方，面板在侧栏区域渲染。注册通道复用现有 bridge；贡献只描述 UI，不授予任何权限。

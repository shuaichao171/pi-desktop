## 额外发现

- Windows 关闭窗口并选择退出时，原代码提前设置 readyToQuit，跳过 before-quit 的服务清理。现在只有清理完成后才允许退出；空闲退出、运行中确认退出、托盘模式选择退出都有回归测试。
- 设置页的“开启”和“关闭”原本都反转当前通知值。现在分别写入 true/false，等待保存成功才更新显示，保存失败保留已保存状态并显示错误。
- 会话跨卷移动引入异步阶段后，切换/删除/关闭必须协调；删除与会话激活串行，并等待在途操作完成后关闭服务。
- 后台工作区仍可能持有正在执行的会话，不能只检查当前窗口的 snapshot。删除前需要 Agent 检查并锁定目标会话，完成或失败后释放锁。
- 嵌套工作区的 Git 路径需要转换到当前工作区；原丢弃流程对 rename 双记录解析不完整，本轮修复并用真实临时仓库验证。
- 嵌套工作区的提交和提交上下文需要限定当前目录，避免把仓库其它目录的更改一起提交，同时保留其它目录已经暂存的内容。
- 从缓存切回长会话时原本漏传 historyTotal，导致 UI 误认为全部历史已经加载；现在保留完整计数。
- 从运行中会话切到空闲会话时，原通知跟踪器会把新会话的 idle 当作旧任务完成。现在会话切换重置通知状态，避免错误通知和错误会话归属。

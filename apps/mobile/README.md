# Pi Desktop Remote (Expo / React Native)

Companion mobile app for controlling Pi Desktop over LAN, Tailscale HTTPS, or Cloudflare Tunnel.

## Architecture

- Shares wire protocol types and the multi-route connection runtime directly from `../../packages/shared/src/remoteAccess.ts` and `../../packages/shared/src/remoteClient.ts`.
- Automatically learns LAN & Tailscale routes advertised by the desktop host and promotes back to direct LAN when on the same Wi-Fi network.
- Stores per-environment session tokens in OS secure storage (`expo-secure-store`) and exchanges them for 60-second single-use WebSocket tickets before opening `/ws`.

## Local Development

Install dependencies inside `apps/mobile` (intentionally isolated from the desktop Electron pnpm workspace):

```bash
cd apps/mobile
npm install
npx expo start
```

Or build native Android / iOS dev clients:

```bash
npx expo run:android
npx expo run:ios
```

### Android release APK (standalone, no Metro)

`android/` is generated by `expo prebuild` and is git-ignored. Requirements: JDK 17, Android SDK
platform 35 + build-tools 35, NDK 27.1.12297006 (Gradle downloads missing SDK parts on first build).

```bash
npx expo prebuild --platform android --no-install
# android/local.properties: use forward slashes, e.g. sdk.dir=E:/Android/sdk
cd android
./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a          # real phones
./gradlew assembleRelease "-PreactNativeArchitectures=arm64-v8a,x86_64"  # + x86_64 emulators
# -> android/app/build/outputs/apk/release/app-release.apk (signed with the debug key)
```

Notes:

- The expo-managed native modules (`expo-asset`, `expo-constants`, `expo-file-system`, `expo-font`,
  `expo-keep-awake`) are direct dependencies on purpose: npm may nest them under `node_modules/expo/`,
  where SDK 53 autolinking cannot see them and the app crashes at launch with
  `Cannot find native module 'ExpoAsset'`.
- Plain-HTTP LAN routes need cleartext traffic in release builds; it is enabled through the
  `expo-build-properties` plugin (`android.usesCleartextTraffic`), not a top-level `app.json` key.
- If the Gradle JVM needs a proxy, pass `-Dhttps.proxyHost=… -Dhttps.proxyPort=…` (Gradle ignores `HTTPS_PROXY`).

## Pairing

1. Open Pi Desktop → **Settings → Remote access**, enable the server (and optionally Tailscale HTTPS or Cloudflare Tunnel).
2. Click **Generate QR** to mint a one-time pairing code (`Full control` or `Read-only`).
3. In this app, tap **Scan QR** (or paste the `pidesktop://pair?...` link).
